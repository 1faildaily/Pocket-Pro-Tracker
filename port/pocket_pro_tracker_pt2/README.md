# Pocket Pro Tracker v0.3.31 — czarne tło / biały tekst

Paleta: Background 600 → 000, Pattern text 000 → FFF.
PATTERN (także pełnoekranowy), POSITION-ED, QUADRASCOPE i obszar przebiegu SAMPLE EDIT mają czarne tło. Tekst patternu jest biały; biały tekst POSITION-ED i przebieg sampla pozostają białe. Czerwone ramki, nagłówki i aktywny wiersz zachowują dotychczasowe kolory.

Zmiana dotyczy tylko colors.ini; funkcje v0.3.30 pozostają zachowane.

Można podmienić samo colors.ini w katalogu programu na karcie i uruchomić PPT ponownie, bez kompilacji. Pełny SourceKit: podmień pliki razem z .github → Commit → Push → artefakt ARM64.
